# TodoFlow

A modern and responsive Todo application built with React.

TodoFlow is designed to help users organize their daily tasks, track progress, and stay focused with a clean and minimal interface.

## Features

- Add tasks
- Edit tasks
- Delete tasks
- Complete and uncomplete tasks
- Search tasks
- Filter tasks
- Task categories
- Task priorities
- Due dates
- Progress tracking
- Dark mode
- Responsive design
- LocalStorage
- Notifications

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Lucide React
