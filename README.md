# TodoFlow

A modern and responsive Todo application built with React, designed to help users organize tasks, track progress, and stay productive.

## 🚀 Demo

Coming soon.

## 📌 About The Project

TodoFlow is a modern task management application built as a React frontend project.

The project focuses on building a clean user interface while implementing real-world React concepts such as state management, reusable components, filtering, searching, local storage, modals, notifications, and theme management.

## ✨ Features

- Add new tasks
- Edit existing tasks
- Delete tasks with confirmation
- Complete and uncomplete tasks
- Clear all completed tasks
- Search tasks
- Filter tasks by priority
- Filter tasks by category
- View All, Active, and Completed tasks
- Dark Mode
- Light Mode
- Persistent data with LocalStorage
- Toast notifications
- Notification center
- Mark notifications as read
- Delete all notifications
- Responsive design
- Reusable React components

## 🛠️ Built With

- React
- JavaScript
- CSS
- Vite
- Lucide React
- LocalStorage

## 💾 Data Persistence

TodoFlow uses the browser's `localStorage` to persist:

- Tasks
- Theme preference
- Notifications

This means the user's data remains available after refreshing or reopening the application.

## 🎨 Theme System

TodoFlow supports both:

- Dark Mode
- Light Mode

The selected theme is saved in LocalStorage and automatically restored when the application is opened again.

## ⚙️ Getting Started

### Prerequisites

Make sure you have Node.js installed on your computer.

### Installation

Clone the repository:

```bash
git clone https://github.com/aminrasooli2007-svg/todo-app-react.git
```

Navigate to the project directory:

```bash
cd todo-app-react
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open the local URL provided by Vite in your browser.
